# ✨ Alexis Portfolio

Portfolio développeur Full Stack réalisé avec Vue 3, TypeScript et Nuxt UI.

---

## ✨ Features

- 🌙 Dark / Light mode
- 📱 Responsive design
- ⚡ Animations fluides avec VueUse Motion
- 🎯 Navigation ScrollSpy
- ⌨️ Texte animé avec Typed.js
- 🧩 Architecture moderne en composants
- 📬 Formulaire de contact avec EmailJS
- 🚀 Performance et UX optimisées
